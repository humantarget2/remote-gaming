Remote PC Launcher

Open the browser-based remote desktop page for a computer you own or are authorized to access.

Important: This file is only a launcher. It does not stream your PC, carry keyboard/mouse input, or create a remote connection by itself. You need a browser-compatible remote desktop service configured on your home PC, and the network you're using must allow access to that service.

Use only on devices and networks where remote access is permitted. This page does not bypass school network restrictions.
